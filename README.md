# AI-Штурман технической поддержки (AI-Navigator)

> **MVP Модуля предиктивного обнаружения массовых инцидентов и аварий провайдеров на базе GigaChat API, RAG и защиты ПДн по ФЗ-152.**

**Проблема**
В выездном сервисе задержка распознавания инфраструктурных сбоев (аварии провайдеров связи, кассового ПО) составляет до 4 часов. Это приводит к сотням холостных выездов инженеров, перегрузке Диспетчерского центра и штрафам за просрок SLA.

**Решение**
«AI-Штурман» в режиме read-only анализирует входящий поток текстовых логов/заявок, маскирует персональные данные по ФЗ-152 и группирует схожие симптомы через векторные эмбеддинги (EmbeddingsGigaR) и GigaChat-2-Max. При обнаружении аномалии система за 15 минут генерирует карточку массового инцидента для аналитика ДЦ (принцип Human-in-the-Loop).

**Технологический стек**
* Python 3.10+
* GigaChat API (GigaChat-2-Max, EmbeddingsGigaR)
* RAG (Retrieval-Augmented Generation) & Vector Database
* Security: Custom Regex Anonymizer (ФЗ-152)

**Безопасность и ФЗ-152**
Все текстовые данные проходят обязательную предварительную обработку на локальном контуре (anonymizer.py). Телефоны, адреса, ФИО и ИНН заменяются на спецтеги ([MASKED_PHONE], [MASKED_ADDRESS]) ДО передачи в языковую модель.

**Быстрый запуск**
1. Клонировать репозиторий:
   git clone https://github.com/your-username/ai-navigator-support.git
   cd ai-navigator-support
2. Создать и активировать виртуальное окружение:
   python3 -m venv venv
   source venv/bin/activate
3. Установить зависимости:
   pip install -r requirements.txt
4. Запустить демонстрационный пайплайн:
   python main.py
